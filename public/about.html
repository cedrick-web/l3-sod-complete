About Us

This student project demonstrates how a website can connect a front end to a Node.js server and a MySQL database.

What the system demonstrates

  • User registration and login.
  • Password hashing using bcrypt.
  • Session-based access to protected pages.
  • Displaying registered users and project information from MySQL.
